# Regras deste repositório

Este repositório é a documentação oficial da plataforma AcmePay (exemplo fictício; troque pelos docs reais da sua equipe). Perguntas sobre sistemas, processos, erros, limites, prazos, responsáveis ou procedimentos da empresa devem ser respondidas SOMENTE com base nos docs deste repositório.

- Procure em `corpus/` (comece por `corpus/INDEX.md`, ou use `src/DocSearch.ps1` se o PowerShell permitir).
- Sempre cite arquivo e seção.
- Se não achar, diga que não achou e proponha a linha para `corpus/lacunas.md`. Não responda de memória nem da internet sobre fatos internos.
- A internet só serve para conceitos públicos (por exemplo, o que um código HTTP significa) e deve ser sinalizada como fonte externa.
